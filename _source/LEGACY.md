# Legacy (Jekyll era, July–September 2026)

Kept for reference only. Nothing in the Astro build reads this folder.

- `rd-innovate-articles-2026-07-16-to-2026-08-13.md` — the original archive the
  first posts were split from.
- `daily-article.sh`, `daily-task-instructions*.md` — the Mac launchd job that
  ran Claude Code at 06:30. Retired in favour of the GitHub Actions workflow:
  it failed every run from 28 Aug 2026 (`OAuth session expired`) and could not
  run while the Mac was asleep. It also writes to `_posts/`, which no longer exists.
- `split_articles.py`, `fix_excerpts.py`, `tag_posts.py`, `sync_categories.py` —
  one-off Jekyll helpers. Category colours now live in `src/data/categories.json`
  and new ones are generated by `src/lib/categories.mjs`.
