## The plateau problem in collaborative robot learning

Aggregating operational experience across autonomous robot fleets without centralising raw sensor data relies on the assumption that client performance metrics reliably indicate policy progress. In federated reinforcement learning for mobile robotics, decentralised edge nodes train local models on local environment interactions and transmit parameter updates back to a central server. This central server aggregates the weights to produce a shared global policy. However, this training pipeline breaks down when deployed across physical environments of varying complexity. An autonomous mobile robot navigating an open corridor faces a dramatically simpler task than a unit attempting to thread through a densely cluttered storage space.

Standard federated aggregation techniques treat local updates with equal weight or weight them proportionally to the episode returns achieved by local agents. Uniform parameter averaging assumes all local environments contribute equally valuable information, which fails when simple tasks dominate the fleet's workload. Weighting parameters by episode return causes an even more severe failure mode. Because simple navigation paths permit high performance scores by construction, a robot operating in an open space consistently reports high returns. Once that robot has mastered its easy route, its local training updates carry virtually no new information to improve the global model. Yet, because its reported returns remain high, standard return-weighted algorithms heavily bias the global model towards these uninformative updates.

This structural flaw, termed the plateau problem, degrades the convergence rate and final accuracy of shared navigation policies. Unhelpful updates from plateaued clients obscure the critical learning signals generated by robots operating in difficult, cluttered spaces. Addressing this imbalance requires an aggregation mechanism capable of distinguishing between high performance stemming from easy conditions and genuine policy improvement gained through overcoming complex operational challenges.

## Inferring difficulty and progress without maps

To resolve the plateau problem without introducing heavy administrative overhead, the proposed aggregation framework—termed FedDIA (Difficulty- and Improvement-Aware Aggregation)—redefines how central servers calculate update weightings. Rather than relying on raw episode returns or static client weights, the system evaluates two dynamic signals for every participating robot in each training round: the degree of local policy improvement and the underlying difficulty of the client's operating environment.

Measuring environment difficulty across decentralised edge nodes often presents a practical barrier, as deployment sites rarely provide standardized visual maps or hand-coded complexity metrics. FedDIA overcomes this constraint by inferring environment difficulty directly from the performance of the incoming global model within that specific environment, without requiring any geometric map or environmental description. Before local training begins in a given communication round, the shared global model is evaluated on the local edge node. If the global model achieves low initial performance in that environment, the framework infers that the local environment presents high navigation difficulty. Conversely, if the global model performs effortlessly upon arrival, the environment is categorised as low difficulty.

Simultaneously, local policy improvement is quantified by measuring how much local training improves upon the global model received at the start of the round. Both metrics—environmental difficulty and local progress—are evaluated relative to the same shared global model baseline. This shared reference frame makes the resulting scores comparable across all edge nodes in the fleet, regardless of local terrain differences.

During global aggregation, the central server computes client weights by scaling local model improvement against environmental difficulty. Updates from edge nodes that demonstrate substantial progress within challenging environments receive higher aggregation weights. Conversely, updates from plateaued nodes operating in trivial environments are downweighted, preventing uninformative parameter shifts from distorting the shared global navigation policy.

## Performance benchmark and stress testing

The FedDIA framework was systematically benchmarked using a mapless mobile robot navigation task executed across an eight-client heterogeneous network. The experimental fleet was deployed in varied environmental configurations to evaluate how effectively the adaptive weighting scheme coped with diverse operational conditions.

Across both active training environments and previously unseen held-out testing environments, FedDIA achieved a mean navigation success rate of 75.5 per cent. In comparative testing against the strongest existing federated reinforcement learning baseline aggregation rules, which reached a mean success rate of 68.7 per cent, the difficulty- and improvement-aware approach maintained a consistent performance advantage. By prioritizing updates that carried high informational value, the global model converged on more effective spatial traversal strategies.

To evaluate generalisation capabilities, the trained global policy was transferred directly to hand-authored layout configurations, including structured warehouse models and cluttered living-space environments. The performance gains observed during initial training carried over to these unmodelled target spaces, demonstrating that filtering out unhelpful updates prevents the model from overfitting to specific edge environments.

Furthermore, the aggregation logic was evaluated under failure conditions where one client within the eight-robot fleet was defective. In standard federated structures, a malfunctioning edge node transmitting corrupted or erratic weight updates can severely degrade the central policy. Under FedDIA, because the defective node failed to demonstrate genuine policy improvement relative to the global benchmark, its aggregation weight was suppressed. This prevented defective updates from destabilising overall fleet learning and maintained performance across the remaining operational units.

## Technical limitations and deployment boundaries

While these findings highlight architectural advantages for decentralised mobile robotics, several boundaries define the scope of the results. The empirical evaluations presented in the study focused specifically on mapless mobile robot navigation tasks. The framework's utility has not been validated for high-dimensional robotic manipulation tasks, multi-arm industrial assembly, or complex joint manipulation scenarios where reward signals are sparse and task boundaries are intricate.

Additionally, the scale of the experimental evaluation was limited to an eight-client network configuration. While this fleet size effectively demonstrated the core plateau phenomenon and validated the mathematical weighting logic, scaling the approach to enterprise deployments involving hundreds or thousands of simultaneous edge units may introduce additional computational or synchronisation overheads.

The mechanism also depends on measuring performance differentials against the incoming global model at each communication round, which requires structured evaluation steps within local client pipelines. Finally, the evaluation relied on mapless simulation tasks and hand-authored transfer layouts. Validating performance under industrial field deployment will require testing against physical telemetry disruptions, variable communication latency, intermittent network connectivity, and physical hardware variations across heterogeneous robot bodies.

## The R&D takeaway

For engineering leaders designing decentralised robotic systems, this research demonstrates that unweighted operational data can actively degrade shared model capabilities when edge environments vary in complexity. R&D strategies for fleet autonomy should shift focus from expanding raw data collection to implementing dynamic evaluation metrics that filter out redundant updates at the aggregation layer. Prioritising update quality over raw node count ensures faster convergence, robust zero-shot generalisation, and systemic fault tolerance across distributed mobile assets.
